
# Customer Segmentation using Clustering 📊

## Overview
A clustering-based web application using Streamlit to perform customer segmentation. The app uses the KMeans algorithm for customer clustering.

## 📁 Project Structure
```
.
├── app.py
├── scripts
│   └── train.py
├── models
│   └── model.pkl
├── utils
│   ├── preprocessing.py
│   └── logger.py
└── data
    └── mall_customers.csv
```

## 🚧 Setup Instructions
- Clone repository and install dependencies with `pip install -r requirements.txt`
- Run Streamlit app with `streamlit run app.py`

## 🛠️ Technologies
- Python, Pandas, Scikit-learn, Streamlit
